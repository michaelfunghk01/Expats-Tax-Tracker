# Expats Tax Tracker

A simple tax estimation prototype for expatriates.

## What’s included

- `index.html` — the app UI and form inputs
- `styles.css` — styling for the page layout and form
- `app.js` — tax estimate logic for income, deductions, and filing status

## How to run

1. Open `index.html` in your browser.
2. Enter your annual income and deductions.
3. Choose filing status.
4. Click **Calculate** to see an estimated tax result.

## Notes

- This is a prototype and uses a simplified tax calculation.
- It is not intended as tax advice.\n\nThis repo contains prototype code for tax application work.
